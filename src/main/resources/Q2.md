# Q2 - Outils de test

- JUnit 5 : permet d'écrire et d'exécuter des tests Java.
- Hamcrest : permet d'écrire des assertions lisibles pour vérifier les résultats des tests.
- Mockito : permet de créer des objets simulés (mocks) afin d'isoler la classe testée de ses dépendances.
- JaCoCo : mesure la couverture du code par les tests.

JaCoCo n'est pas une bibliothèque de test, c'est un outil de mesure de couverture de code.
